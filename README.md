# NEXORA 🚀

## Powering the Next Generation of Social Growth

NEXORA is an AI-powered social media growth platform that helps creators, brands, and businesses grow their online presence.

## Core Features

- AI Social Media Tools
- Growth Services Marketplace
- Customer Dashboard
- Admin Dashboard
- API Provider Management
- Payment System
- Affiliate Program
- SEO Content Hub

## Platforms Supported

- Instagram
- TikTok
- YouTube
- Facebook
- X
- Telegram
- Discord
- LinkedIn

## Technology Stack

Frontend:
- Next.js
- Tailwind CSS

Backend:
- Node.js

Database:
- PostgreSQL

Deployment:
- Vercel
